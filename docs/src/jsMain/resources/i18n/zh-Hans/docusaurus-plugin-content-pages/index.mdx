<ktjs-features section-title="这套封装给你什么" tinted>

<ktjs-feature icon="lucide:component" title="元素也是类型">`<iconify-icon>` 声明成 external class：`icon`、`mode`、`inline`、`width` / `height`、`rotate` / `flip`、`status` 全是 Kotlin 属性。</ktjs-feature>

<ktjs-feature icon="lucide:palette" title="不发请求也能有图标">`addIcon` / `addCollection` 本地注册数据；想走 Iconify API 时用 `loadIcon` / `loadIcons`。</ktjs-feature>

<ktjs-feature icon="lucide:cpu" title="SVG 与 CSS 生成">`iconToSVG`、`iconToHTML`、`getIconCSS` / `getIconsCSS` 与定制项，来自 `@iconify/utils`。</ktjs-feature>

<ktjs-feature icon="lucide:folder-tree" title="构建期工具">Node 里的 `@iconify/tools`：`SVG`、`IconSet`、`importDirectory` / `exportIconPackage`、`cleanupSVG`、`runSVGO`、`parseColors`。</ktjs-feature>

<ktjs-feature icon="lucide:shapes" title="共享类型">`@iconify/types` 声明了 `IconifyJSON`、`IconifyIcon`、`IconifyAlias` 与其他模块依赖的定制项记录。</ktjs-feature>

<ktjs-feature icon="lucide:languages" title="文档与演示都有中英">文档与演示页都能在英文与简体中文之间切换。</ktjs-feature>

</ktjs-features>
