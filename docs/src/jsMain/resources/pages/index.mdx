<ktjs-features section-title="What the wrappers give you" tinted>

<ktjs-feature icon="lucide:component" title="The element, typed">`<iconify-icon>` as an external class: `icon`, `mode`, `inline`, `width` / `height`, `rotate` / `flip` and `status`, all Kotlin properties.</ktjs-feature>

<ktjs-feature icon="lucide:palette" title="Icon sets without an API call">`addIcon` / `addCollection` register data locally; `loadIcon` / `loadIcons` fetch from the Iconify API when you want it.</ktjs-feature>

<ktjs-feature icon="lucide:cpu" title="SVG and CSS generation">`iconToSVG`, `iconToHTML`, `getIconCSS` / `getIconsCSS` and `iconToSVG` customisations come from `@iconify/utils`.</ktjs-feature>

<ktjs-feature icon="lucide:folder-tree" title="Build-time tooling">`@iconify/tools` in Node: `SVG`, `IconSet`, `importDirectory` / `exportIconPackage`, `cleanupSVG`, `runSVGO`, `parseColors`.</ktjs-feature>

<ktjs-feature icon="lucide:shapes" title="Shared types">`@iconify/types` declares `IconifyJSON`, `IconifyIcon`, `IconifyAlias` and the customisation records the other modules build on.</ktjs-feature>

<ktjs-feature icon="lucide:languages" title="Docs and demo in two languages">The documentation and the demo page both switch between English and Chinese.</ktjs-feature>

</ktjs-features>
